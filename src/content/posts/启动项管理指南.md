# 

> 手动把任何程序加入 / 取消开机自启动的常用方法。
> 日常记住前两个就够了：**加自启用启动文件夹，关自启用任务管理器。**

---

## 方法一：启动文件夹（最直观，推荐）

适合：任何程序、脚本（.exe / .bat / .pyw / 快捷方式）

### 添加自启

1. 按 `Win + R`，输入 `shell:startup`，回车
   （会打开：`C:\Users\<用户名>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup`）
2. 把程序的**快捷方式**（右键程序 → 发送到 → 桌面快捷方式，再剪切过来）或程序文件本身放进去
3. 重启或注销重新登录即可生效

### 取消自启

- 删除启动文件夹里对应的文件即可
- 删的只是"启动入口"，程序本身不受任何影响

### 全机生效（所有用户）

- `Win + R` 输入 `shell:common startup`，操作相同，但需要管理员权限

---

## 方法二：任务管理器（快速开关现成的启动项）

适合：批量查看和临时禁用，不删文件、随时恢复

1. 按 `Ctrl + Shift + Esc` 打开任务管理器
2. 切换到 **「启动应用」** 标签页（Win10 也叫「启动」）
3. 选中任意程序，右键 → **「启用」/「禁用」**

> Win11 也可以走：**设置 → 应用 → 启动**，用开关直接控制。
> 这里能看到来自启动文件夹、注册表等处的所有自启项及其对开机速度的影响评级。

## 方法三：注册表 Run 键（程序多、想精确控制时）

适合：进阶用户，适合批量管理大量自启项

### 操作步骤

1. `Win + R` 输入 `regedit` 回车
2. 定位到（当前用户级）：

   ```
   HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
   ```

3. **添加**：右键空白处 → 新建 → 字符串值
   - 数值名称：随便起（一般用程序名）
   - 数值数据：程序的完整路径，例如 `"C:\Program Files\App\app.exe"`
4. **取消**：右键删除对应的值即可

### 两个位置的区别

| 位置 | 生效范围 | 权限要求 |
| --- | --- | --- |
| `HKEY_CURRENT_USER\...\Run` | 仅当前用户 | 普通 |
| `HKEY_LOCAL_MACHINE\...\Run` | 所有用户 | 管理员 |

> 某些杀毒软件、驱动类程序会写在 `HKEY_LOCAL_MACHINE` 下。
> 修改注册表前建议先备份：文件 → 导出。

## 方法四：软件自身的设置（优先用这个）

很多常用软件都内置了开关，效果等价且最干净：

- 微信 / QQ：设置 → 通用 → 开机自动启动
- Steam：设置 → 界面 → 计算机启动时运行
- Snipaste：首选项 → 通用 → 开机自启
- 浏览器（Edge/Chrome）：设置 → 系统 → 打开…

如果目标软件有这个选项，**优先在软件里关，而不是去启动文件夹/注册表删**，避免软件下次更新时又把自己加回去。

## 方法五：任务计划程序（进阶，带条件触发）

适合：需要"延迟启动""仅接通电源时启动""错过时机补跑"等条件

1. `Win + R` 输入 `taskschd.msc` 回车
2. 右侧「创建基本任务」→ 按向导走
3. 触发器选 **「登录时」**（可选延迟固定时间）
4. 操作选「启动程序」，浏览到目标 exe
5. 取消自启：在任务计划程序库中找到该任务，禁用或删除

> 常见用法：开机 30 秒后再启动某软件，避开开机高峰抢资源。

## 常见问题

**Q：改完要重启才生效吗？**
A：注销重新登录即可验证，不必重启整机。

**Q：任务管理器里"禁用"和删除文件有什么区别？**
A：禁用只是开关（可随时恢复），删除文件是彻底移除。启动文件夹里的文件被禁用后仍在磁盘上。

**Q：怎么排查"开机变慢是哪个程序拖的"？**
A：任务管理器 → 启动应用，看「启动影响」列（高/中/低）；也可以在「详细信息」里按 CPU/磁盘排序观察开机后几分钟的情况。

**Q：启动文件夹里的文件双击能跑，但开机不自启？**
A：检查任务管理器 → 启动应用里该条目是否被"禁用"了；被禁用的启动文件夹条目不会运行。

## 快速对照表

| 需求 | 操作 |
| --- | --- |
| 给某程序加自启 | `shell:startup` 放快捷方式 |
| 关掉某个自启 | 任务管理器 → 启动应用 → 禁用 |
| 彻底删除自启 | 启动文件夹删文件 / 注册表删值 |
| 延迟/条件自启 | 任务计划程序 `taskschd.msc` |
| 本工具（目标横幅） | 启动文件夹中的 `目标置顶横幅.pyw`，删掉即取消自启 |
